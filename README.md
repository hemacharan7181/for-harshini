# For Harshini 💗
A small interactive congratulations site.

## GitHub Pages
Upload the contents of this folder to the root of a GitHub repository. Enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

The site uses MP4 versions of the supplied GIFs inside `<video autoplay loop muted playsinline>` so the animations reliably play on mobile browsers and GitHub Pages.
